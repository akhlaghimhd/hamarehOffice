# تصمیم مهاجرت رابط کاربری

**وضعیت:** تصمیم مصوب برای پروژه جدید؛ انتخاب الگوی اتصال Vue نیازمند spike.

Filament در پروژه جدید مبنای UI نیست و نباید نصب شود. Backend با Laravel و دیتابیس MariaDB حفظ می‌شود؛ Vue 3 لایه ارائه خواهد بود.

## معیارهای تصمیم
اولویت مالک: توسعه سریع، آزادی CSS، UX موبایل ممتاز، سفارشی‌سازی بدون محدودیت پنل‌ساز و deploy روی هاست اشتراکی. راهکارهای شبیه Filament در دامنه انتخاب نیستند.

## گزینه باز
انتخاب Inertia در برابر Blade + Vue/API هنوز نهایی نیست. نمونه قبلی در branch آزمایشی، Blade همراه Vue و fetch JSON است و Inertia محسوب نمی‌شود. هر گزینه باید از نظر auth/session/CSRF، routing، validation، state، build، پیچیدگی نگهداری و deploy روی هاست بررسی شود.

## اصول انتقال
منطق دامنه و مجوز در Laravel؛ Vue فقط ارائه. هویت و مجوز واحد حفظ شود. انتقال کد یا schema قدیمی کورکورانه ممنوع. ابتدا vertical slice محدود شامل ورود، انتخاب شرکت، مجوز، فهرست/جزئیات و عملیات نمونه ساخته و روی محیط هم‌ارز هاست deploy شود؛ سپس معماری تعمیم یابد.

## ممنوعیت
Filament جدید، login/role موازی، منطق حیاتی در Vue، Node runtime دائمی و فرض Inertia بودن prototype.
