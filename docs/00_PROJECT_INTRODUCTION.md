# معرفی پروژه هم‌ره و راهنمای همکاری

**مخزن جاری:** `akhlaghimhd/hamarehOffice` | **شاخه:** `main`  
**منبع دانش تاریخی:** `akhlaghimhd/hamarehCRM` | `feature/filament5-upgrade`

## محصول
هم‌ره سامانه عملیاتی یکپارچه، چندشرکتی و داده‌محور برای مدیریت ارتباط با مشتری، بازاریابی، کاتالوگ و پیکربندی محصول، پیش‌فاکتور و سفارش، ارجاع تولید به پیمانکار، وظایف، مالی عملیاتی و موجودی است. هدف اتصال داده، مجوز، اسناد و رویدادهای عملیاتی است؛ نه مجموعه‌ای از صفحات CRUD مستقل.

## جهت‌گیری فنی
- Backend: Laravel؛ نسخه دقیق پس از بررسی محیط واقعی و هاست هدف تثبیت می‌شود.
- UI: **Vue 3 + Inertia + Tailwind CSS + shadcn-vue** (مصوب 2026-11-21).
- Filament در پروژه جدید استفاده یا نصب نمی‌شود.
- Database: MariaDB.
- هویت، نشست، عضویت شرکت، نقش و مجوز یکپارچه؛ بدون سامانه موازی.
- فارسی، RTL، mobile-first، اعداد فارسی در نمایش و تاریخ شمسی در UI.
- Node/Vite فقط برای build؛ Node runtime دائمی روی هاست لازم نیست؛ SSR خاموش.
- مقصد استقرار هاست اشتراکی است.

جزئیات تصمیم UI: `04_UI_MIGRATION_DECISION.md`.

## اصول قطعی دامنه
1. ایزوله‌سازی داده عملیاتی با `company_id`؛ `tenant_id` ممنوع.
2. منطق کسب‌وکار در Laravel و Action/Service/Domain مناسب است، نه Vue.
3. کاتالوگ، ویژگی، گزینه، ترکیب مجاز، قیمت و Workflow تا حد ممکن داده‌محور و نسخه‌دارند.
4. سفارش تأییدشده Snapshot نسخه‌دار و immutable دارد.
5. تولید فعلی مبتنی بر ارجاع به پیمانکار و بسته‌های کاری است؛ معماری توسعه عملیات داخلی را مسدود نمی‌کند.
6. موجودی سبک و رویدادمحور است؛ جلد و داخله مستقل‌اند؛ رزرو، انتقال به تولید، مصرف، ضایعات، محصول آماده و تحویل رویدادهای مستقل‌اند.
7. اعداد فارسی در UI و ورودی normalize شده؛ داده ذخیره‌شده استاندارد و قابل محاسبه است.
8. تاریخ در UI شمسی و در ذخیره‌سازی استاندارد است.
9. تمام نام فایل‌ها و پوشه‌ها انگلیسی‌اند؛ متن مستندات می‌تواند فارسی باشد.

## منبع حقیقت
مخزن جدید مرجع وضعیت جاری است. مخزن قدیمی فقط برای استخراج دانش و شواهد خوانده می‌شود. مالک تصمیم‌گیر نهایی محصول و معماری است.

## گردش کار
ابتدای هر کار branch، HEAD، remote و working tree را بررسی کن؛ سند و کد مرتبط را بخوان؛ تصمیم، نیازمندی، کد قدیمی، تست قدیمی، prototype و وضعیت جدید را تفکیک کن؛ تغییر حداقلی و قابل ردیابی انجام بده؛ تست مرتبط را اجرا یا باقی‌ماندن آن را اعلام کن؛ Commit انگلیسی Conventional و گزارش فارسی ارائه کن.
