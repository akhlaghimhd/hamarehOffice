# UI Lab (موقت)

بخش مرجع ظاهر Materio برای یکدست‌سازی UI قبل از ادامهٔ فرم‌های عملیاتی.

## هدف
- الگوی درست دکمه، کارت، تب، فرم، دیالوگ بدون تکرار توضیح
- بازپیاده‌سازی ظاهر Pro به‌صورت محلی (بدون لایسنس / بدون upsell)

## مسیرها
- فهرست: `/ui-lab`
- صفحات نمونه: `/ui-lab/*`
- منو: «الگوهای UI (موقت)»

## حذف بعد از تثبیت
1. پوشه `frontend/src/pages/ui-lab/`
2. روت‌های `ui-lab` در `routes.ts`
3. بلوک منو در `NavItems.vue`
4. این سند

## وضعیت
- آماده: عناصر پایهٔ پرکاربرد + فرم‌های اصلی
- در صف: card-advance/widgets/statistics/gamification، data-table، apex، kanban، form-wizard، swiper
