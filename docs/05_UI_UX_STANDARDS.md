# استانداردهای UI/UX

**استک مصوب:** Materio Free + Vue 3 + Vuetify 3  
**زبان UI:** فارسی | **جهت:** RTL

## اصول
- mobile-first؛ در موبایل امکان ناوبری پایین‌صفحه (bottom navigation) مجاز و مطلوب است.
- ظاهر از پوسته Materio؛ سفارشی‌سازی از theme Vuetify و Layout پروژه.
- بنر یا منوی «Upgrade to Pro» در محصول نهایی **ممنوع** است.
- فونت فارسی محلی (مثلاً Vazirmatn/Vazir) بدون وابستگی اجباری به CDN خارجی در production.
- اعداد در نمایش فارسی؛ نرمال‌سازی ورودی برای ذخیره.
- تاریخ شمسی در UI.

## لایه‌ها
- Layout اصلی (سایدبار دسکتاپ + رفتار موبایل) یک‌بار تعریف می‌شود؛ صفحات دامنه فقط محتوا می‌آورند.
- رنگ و تایپوگرافی از theme متمرکز؛ از hardcode پراکنده پرهیز شود.

## دسترسی و حالت خالی
- خطای مجوز با پیام فارسی واضح.
- empty state و loading یکدست.
