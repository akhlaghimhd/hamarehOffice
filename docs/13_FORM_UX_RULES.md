# قوانین UX فرم‌ها — هماره

نسخه: 1.0.0  
وضعیت: **اجباری برای UI Materio**

## ۱) اعداد
- نمایش همه ارقام در UI با **ارقام فارسی** (`toFaDigits`).
- فیلدهای عددی: `inputmode="numeric"` / `type="tel"` یا number برای کیبورد موبایل.
- فقط رقم پذیرفته شود (ارقام فارسی ورودی به لاتین نرمال می‌شوند).

## ۲) مبلغ (ریال)
- واحد ذخیره‌سازی و قرارداد دامنه: **ریال**.
- نمایش با **جداکننده هزارگان** + ارقام فارسی.
- کامپوننت: `MoneyField`.

## ۳) تلفن / موبایل
- حداکثر و هدف: **۱۱ رقم**.
- موبایل: الگوی `09xxxxxxxxx`.
- کامپوننت: `PhoneField`.

## ۴) تاریخ
- ورودی فقط از **تقویم شمسی (Date Picker)** — نه تایپ آزاد کاربر.
- ذخیره API: `Y-m-d` میلادی.
- نمایش: شمسی + ارقام فارسی.
- کامپوننت: `JalaliDateField`.

## ۵) دکمه‌ها (اولویت عمل)
| عمل | رنگ / ظاهر |
|-----|------------|
| عمل اصلی (ثبت، ذخیره، بستن گام) | `color="primary"` solid |
| عمل ثانویه (اعمال فیلتر، خنثی) | `variant="tonal"` + `secondary` یا tonal |
| انصراف / بازگشت | `variant="text"` + `secondary` |
| خطرناک (حذف، خروج بدون ذخیره) | `color="error"` |

## ۶) پیام‌ها و اعتبارسنجی
- همه پیام‌های validation **فارسی**.
- موفقیت / خطا / هشدار از **Snackbar** (`useNotify`) با رنگ متناظر — نه فقط `alert` ثابت در صفحه.

## ۷) ظرف فرم
- فرم‌های ایجاد/ویرایش در **دراور سمت راست** (`FormDrawer`).
- بستن با تغییر ذخیره‌نشده → تأیید (dirty confirm).

## ۸) تصویر و کاراکتر
- از تصاویر موجود قالب (مثل trophy / صفحات دمو) در هدر دراور یا کارت‌های خالی **با sparingly** استفاده شود.
- هدف: جذابیت بدون شلوغی.
